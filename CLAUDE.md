# GemTD – instruktioner för Claude Code

Projektets gemensamma regler står i AGENTS.md och gäller även här:
@AGENTS.md

Pågående design-/grafikarbete och hur det verifieras:
@docs/redesign-handoff.md

Viktigast: ändra aldrig spelregler eller balans utan att användaren uttryckligen bett om det. Kör `python tools/redesign_guard.py` (ska ge RED_ZONE_OK) och `python tools/check.py` efter ändringar. Gör inga commits om användaren inte ber om det.
